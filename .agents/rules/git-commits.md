# Reglas de Git Commits

- Todos los mensajes de commit (título y cuerpo/descripción) deben redactarse en español.
- Usar formato de conventional commits con título descriptivo en español (ej. `feat: ...`, `fix: ...`, `refactor: ...`, `docs: ...`).
- Incluir una descripción detallada en español que explique los cambios realizados y su contexto cuando el cambio lo amerite.
